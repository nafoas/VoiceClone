# Gold standard: rebuild of the reference clip

`rebuild_gold_v9.wav` is the Bnuy-synth rebuild of "nannarmunis... pee tee tee"
that Da Boss judged near-perfect (v9). Scores against the clip are in
`rebuild_gold_v9_scores.txt` (from `python scripts/iterate.py`).

Any change to the synthesizer must keep the rebuild at least this good:
re-run `scripts/iterate.py` and compare against these numbers (and listen).
